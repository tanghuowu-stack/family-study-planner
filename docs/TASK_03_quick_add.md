# TASK_03 · 新建任务表单简化

> **推荐模型：Sonnet**（单一表单组件的交互改造，逻辑中等）
> **前置依赖：TASK_02 之后更佳**（课程库做完，快速添加能直接选课程）
> **先读**：`PROJECT_GUIDE.md`，再读本卡。

---

## 解决什么问题

用户反馈："新建任务步骤太多，要点很多次。" 现在表单把所有选项一次性铺开（一级分类→二级类型→标题→任务类型→日期→适用阶段→未完成处理→开始时间），日常加个任务很繁琐。

核心洞察：加任务有两种场景，应拆开——
- **快速添加（约 80%）**：只要分类 + 标题 + 日期，一步搞定。
- **详细设置（约 20%）**：重复规则、阶段、未完成处理、时间段等，折叠藏起来。

---

## 要做的事

1. **默认只显示 3 个字段**：
   - 分类（用图标按钮一行平铺选择，不用下拉；接 TASK_02 课程库则可直接选课程）
   - 标题输入框
   - 日期（默认今天）
   其余字段全部给合理默认值：任务类型=指定一天、适用阶段=全部阶段、未完成处理=保留原日期并标记逾期。

2. **"更多设置 ▾"折叠区**：点开才出现任务类型、起止日期、重复规则、适用阶段、未完成处理、开始时间、日历可见性等。

3. **保存按钮始终可点**：只要有标题就能存，不强制填完所有项。

4. **保持数据写入逻辑不变**：只改表单的"呈现和默认值"，最终走 App.tsx 现有的统一新建逻辑，不动底层 repository。

---

## 多端注意

- 手机/iPad 上分类按钮、标题框、保存键要够大，触控友好（孩子也会用）。
- 桌面端可以信息密度高一点。

---

## 不要做

- 不要改任务的数据结构或保存逻辑。
- 不要删除任何高级选项，只是折叠。

---

## 验收标准

1. 打开新建任务，默认只看到 3 个字段，填标题即可保存。
2. 常见任务（今天的语文作业）3 步内完成，明显比现在少点。
3. 点"更多设置"能展开全部原有选项，功能不丢。
4. 手机端按钮大小适合触控。

---

## 开场提示

```
读 PROJECT_GUIDE.md 和 TASK_03_quick_add.md。

告诉我哪些进"快速区"、哪些进"更多设置"折叠区，确认后再改。
只改表单呈现和默认值，不动底层保存逻辑。
```
