# 小步计划 · UI 样式规范

> 全站 UI 的唯一视觉参照。新增页面和组件应复用本文 token 与布局，不在业务组件中另起一套风格。

## 1. 产品气质

小步计划是一套家庭执行工具，不是营销页，也不是儿童插画应用。界面应安静、清楚、耐看，方便每天反复使用。

- 信息层级优先于装饰。
- 使用少量明确色彩，不让整页被单一绿色或紫色占满。
- 页面区块尽量用留白和分隔线组织；卡片只包裹真正独立的信息单元。
- 桌面端使用固定侧栏，移动端使用顶部品牌栏与底部导航。
- 不使用渐变、装饰光斑、大面积毛玻璃或夸张阴影。

## 2. 色板

颜色同时注册在 `tailwind.config.js` 和 `src/styles/index.css`。

| Token | 色值 | 用途 |
|---|---:|---|
| `ink` | `#202925` | 正文、桌面侧栏、月历表头 |
| `paper` | `#F4F2ED` | 页面底色 |
| `primary` | `#245747` | 链接、选中态、完成态 |
| `mint` | `#DCEAE3` | 轻选中背景、柔和反馈 |
| `alert` | `#E36B4E` | 新建等关键行动、逾期提醒、当前位置标识 |
| `muted` | `#6E7772` | 辅助信息 |
| `sun` | `#EFC66A` | 未同步等警示 |

颜色语义：

- 深松墨 `ink/primary` 负责结构与稳定感。
- 珊瑚橙 `alert` 只用于需要立刻注意或执行的元素，不用于大面积背景。
- 学科只用 8px 色点加文字区分（语文 `#D96A52`、数学 `#5868C8`、英语 `#9364C7`、其他 `#8A948F`，定义在 `components/GroupHeading.tsx` 的 `SUBJECT_DOT`）。今日页与任务管理页的分组标题统一用 `GroupHeading`：13px 半粗、无底色、无左边线，分组之间只用细分隔线。不再使用整条浅色学科底、4px 学科左边线，也不再给每条任务加学科色块。
- 任务管理页的大类标题（学校作业 / 课外 / 兴趣班 / 事项）只用文字，不加彩点，避免与学科色点撞色。
- 进度条用 `primary`，`alert` 只留给新建按钮和逾期。
- 危险删除使用 Tailwind `rose`；课程、状态等业务色沿用各自已有语义。

## 3. 应用框架

### 品牌图标

- 唯一品牌图标是“打卡点阵”：3×3 圆点，右上角橙点（`alert`）表示今日，其余为深绿/浅绿（已完成/待做），底色 `#F4F2ED`。
- 源文件在 `public/`：`icon.svg`（原图）、`icon-1024.png`（原图位图）、`favicon.svg` / `favicon.ico` / `favicon.png`（浏览器标签）、`apple-touch-icon.png`（180）/ `-167` / `-152`（iOS 主屏）、`icon-192.png` / `icon-512.png`（PWA manifest）。
- 页面内的 logo 一律用 `<img src="/favicon.svg">`，不再使用 Lucide 的日历图标做品牌；旧图标已删除，不要恢复。
- 换图标后必须把 `public/sw.js` 的 `VERSION` 加一，否则 Service Worker 会先给缓存的旧图标。

### 桌面端（`lg` 及以上）

- 固定左侧栏宽 `14rem`，背景 `ink`。
- 品牌、新建任务、一级导航和云同步状态都在侧栏中。品牌 logo 为 40px 打卡点阵图标（`/favicon.svg`，`h-10 w-10 rounded-lg`）。
- 主内容通过 `.app-content` 留出侧栏宽度。
- 内容最大宽度由页面决定：今日 `max-w-3xl`（清单行不宜过长，标题与右侧进度、操作在一眼范围内），任务管理 `max-w-4xl`，月计划 `max-w-7xl`，统计 `max-w-5xl`。

### 移动端

- 顶部栏高 `h-14`，显示品牌（32px 打卡点阵图标 `/favicon.svg` + “小步计划”）、同步点和新建图标；今日页在新建图标左侧增加“备忘”次级按钮，点击打开并聚焦备忘录输入框。
- 底部导航使用纯白半透明背景，选中项用顶部 `alert` 短线标识。
- 页面必须使用 `pb-content` 避开底栏与 iPhone 安全区。
- 侧栏备忘录在窄屏改放今日页表头与清单之间；有内容或主动打开编辑时显示，空白编辑框不显示占位提示，失焦且为空时隐藏。输入框随内容增高。

### 侧栏备忘录

- 桌面端放在“课表”导航下方，使用侧栏深色体系中的低对比输入框。
- 输入框最少三行，随输入、换行和可用宽度自动增高或缩小，完整显示内容。内容超过视口时由整个侧栏滚动，导航和同步状态均可到达。
- 完成按钮使用勾选图标；完成后归档到历史备忘并清空当前内容。窄屏内容为空且未编辑时不渲染备忘录区。
- 历史备忘位于“统计与设置 → 更多设置”，默认折叠，使用细分隔线列表展示完成时间和完整文字，保留最近 50 条。恢复、永久删除按钮点击区至少 44px；永久删除需二次确认。恢复追加到当前备忘，避免覆盖已有文字。

## 4. 页面标题

今日、月视图、任务管理、统计与设置、课表共用 `.page-header` 和 `.page-title`：

- 页面表头固定高 `5rem`（80px），底部边线、内边距和后续内容间距一致；手机、iPad、Mac 同一规则。
- 主标题字号：手机 `20px / 24px` 行高，iPad `24px / 32px`，Mac `30px / 36px`，统一加粗。
- 操作按钮与辅助日期放在同一表头内；窄屏时月视图只显示翻月箭头，今日页极窄屏可将日期导航放到第二行，保持表头总高度。
- 标题默认左对齐。课表的日期和学期名是辅助信息，不改变主标题规格。

## 4.5 字号层级

页面内容只用以下几级，不再出现 10px、11px：

| 层级 | 规格 | 用途 |
|---|---|---|
| 页面标题 | 见 §4 | `.page-title` |
| 区块 / 任务标题 | 16px（`text-base`），区块加粗、任务半粗 | 今日清单、已完成、逾期未完成、任务名 |
| 正文 | 15px | 小项、需要阅读的正文 |
| 控件 | 14px（`text-sm`） | 按钮、输入框、菜单 |
| 辅助 | 13px | 分组标题、时间、计数、备注、顺延说明、徽章 |

时间用常规字体加 `tabular-nums`，浅底小圆角，不再用等宽小字。

## 5. 表面与圆角

`.surface` 是主要信息容器：白色、`1px` 低对比边框、轻阴影、`8px` 圆角。

| 元素 | 规则 |
|---|---|
| 主信息容器 | `.surface` |
| 输入框、命令按钮 | `rounded-lg`（8px）|
| 小标签 | `rounded` / `rounded-md` |
| 状态点、头像式计数 | 可使用 `rounded-full` |
| 弹窗 | 移动端顶部可贴边，桌面端 `rounded-lg` |

禁止卡片套卡片。分组内部优先使用分隔线、浅底标题条或左边线。

## 6. 按钮与控件

- 关键命令：`bg-alert text-white`，例如“新建任务”“保存任务”。
- 常规确认：`bg-primary text-white`。
- 次级命令：白底、`border-ink/10`、`text-muted`。
- 图标命令优先使用 Lucide 图标并提供 `aria-label` / `title`。
- 筛选使用下划线标签页或分段控件，不使用一排彩色药丸。
- 二元设置使用 checkbox/toggle；日期、数字和选项继续使用对应原生控件。

## 7. 任务列表

- 任务行为紧凑的工作列表，不是独立浮动卡片。
- 行之间使用 `border-ink/[0.07]`；hover 仅出现极浅灰底。
- 主勾选框视觉 28px、点击热区 44px；小项勾选框视觉 20px，小项**整行可点**，行高鼠标设备 32px、触屏（`pointer: coarse`）44px。任务行“…”按钮触屏热区同为 44px。
- 带小项的**非重复**任务左侧不放整体勾选框，改为 28px 只读进度环；小项全部勾完后自动完成，不提供一键全勾。重复类任务的小项跨天共用一份、当天是否完成记在单日状态上，仍保留整体勾选框。
- 逾期区由分区标题表达状态，行内不再重复“已逾期”胶囊；顺延或逾期任务只标“原定 M月d日”。
- 任务行操作菜单点菜单外或按 Esc 关闭。
- 勾选的反馈在行内完成：勾选框动画 + 标题划线变灰，刚完成的任务在原位停留约 0.7 秒再收进“已完成”，进度条和“还剩 N 项”立刻更新。勾选成功**不弹提示**；只有补记到过去日（“已记为 M/D 完成”）和同步失败才提示。
- 标题 `text-base font-semibold`（16px），标签与备注 13px，不能抢过标题。
- checklist 用左边线缩进表示从属关系，小项文字 15px。
- 今日页“已完成”区平铺，不再按学科重复分组；任务行不再挂“已完成”胶囊（划线和所在区已说明），只保留“进行中 / 已取消”。
- 完成任务使用灰字和删除线；未同步徽章持续可见并可点击重试。

今日清单标题栏只放一条进度条和一句“还剩 N 项 / 全部完成”，两者同一口径（有小项按小项计，没有小项按任务计）。

查看的不是今天时，表头下方显示整行提示条（`sun` 浅底）：“正在看 M月d日（昨天/明天/N 天前…），不是今天”加“回到今天”按钮，不再用表头里的小标签。跨零点、或页面在后台超过 30 分钟后回到前台，今日页自动回到今天。

今日页分组规则不变：

1. “上课”由 `isCourseTask` 统一判定，不再按学科拆卡。
2. 其余内容归“作业”，再按 `taskSubjectGroup` 分语文、数学、英语、其他。
3. 带时间任务置顶；无时间任务支持组内拖拽；作业学科组支持整组拖拽。
4. 空分组不渲染，每个任务必须且只能进入一个分组。

## 8. 月计划

- 月历是数据表格：深色星期表头、细网格线、白底日期单元格。
- 今日用 `alert` 实心日期块标记；选中日用 `mint` 浅底。
- 手机单元格最多显示两条短标签和余量数字，点击后在月历下方展开详情。
- 桌面点击日期直接进入当日页。

## 9. 表单与弹窗

- 表单标题栏使用 `ink`，主保存按钮使用 `alert`。
- 表单标签为小号加粗大写式辅助标题；输入内容仍保持正常中文阅读样式。
- 小项位于任务标题下方；“顺延 / 跳过 / 标记逾期”在常用区以分段按钮显示。
- 日期段与重复设置使用紧凑网格；开始和结束时间固定对齐，阶段、备注与可见性留在详细设置中。
- 计时、预计用时与实际用时不再出现在任务界面；已有数据字段保留以兼容历史记录。
- 遮罩使用 `bg-ink/45`，弹窗阴影只用于区分前后层级。

## 10. 可访问性与响应式

- 所有纯图标按钮必须有可读名称。
- 可点击目标尽量不小于 36px；移动端主要动作不小于 40px。
- 文字不得依赖颜色单独表达状态。
- 长标题和长标签必须允许换行或截断，不能推动操作按钮出屏。
- `prefers-reduced-motion` 下关闭非必要动效。
- iOS PWA 继续使用 `.pt-safe`、`.bottom-nav-safe`、`.pb-content` 与 toast 安全区类。

## 11. 日期与课表

- 今日页日期与节日、节气紧邻显示；手机可将星期放在日期下一行，极窄屏的导航可移至第二行，表头总高度仍与其他页面一致。
- 课表采用细网格，课节时间显示在左边，休息时间接在休息名称后。
- 仅明天的工作日列使用强调表头和浅底；今天与其他列保持常态。
- 课程名称加粗，括号内的“葫芦丝 / 课本”为 10px 辅助文字。
- 连续相同的延时课程合并显示，周一、周二延时课间活动合并为一格。
- 需要携带课本或工具的课程名称使用 `mint` 浅底和小圆角标注；课表底部用小号辅助文字解释标注含义。编辑课表时每个课程格可用复选框单独调整高亮。
