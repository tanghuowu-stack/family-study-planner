# 学习生活规划系统：当前状态

更新日期：2026-06-22

## 已完成

- 技术栈为 React、Vite、TypeScript。
- 数据使用 IndexedDB 本地存储，并保留 JSON 导入导出兼容机制。
- 一级分类已稳定为学校作业、课外、兴趣班、事项。
- 阅读计划已从业务界面移除；旧数据继续兼容，不影响页面运行。
- 今日清单按语文、数学、英语、其他上下分区展示。
- 周计划、每日安排、本周汇总和本月计划已完成。
- 日期范围作业按唯一任务汇总，课程按实际次数统计，旅游按天统计。
- 月历只显示上课、兴趣课程及事项等计划类项目。
- 任务管理支持分类分组、阶段筛选、批量删除和软删除。
- 任务管理的已完成区域默认只展示最近 30 天，可查看更早历史。
- 支持任务小项、重复排期、指定日期多选、单次取消和延期。
- 打印 / 备份 / 设置页已提供打印、JSON 备份、本机名称、日历提示和操作日志。
- 课程节数统计支持自定义开始日期和结束日期，并排除取消课程、钢琴练习和软删除任务。
- 已准备 Vercel 静态部署所需的构建方式与云端迁移文档。

## 尚未接入

- Supabase 尚未接入。
- 当前没有登录、家庭成员权限、RLS 或云同步。
- 当前仍以浏览器本地 IndexedDB 为唯一业务数据源。

## 部署状态

- `npm run build` 可生成 Vercel 可用的静态 `dist` 目录。
- Vercel 静态部署处于准备阶段。
- 后续云端迁移方案见 `docs/cloud-migration-plan.md`，未收到明确任务前不要实施。
