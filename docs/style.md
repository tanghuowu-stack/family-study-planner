# 小步计划 · UI 样式规范

> 全站 UI 的唯一视觉参照，只写**现在是什么样**。改动的来龙去脉记在 `change-log.md`（更早的在 `change-log-archive.md`）。
> 新增页面和组件复用本文的 token 与布局，不在业务组件里另起一套风格。积分规则以 `TASK_09_points.md` 为准，记账规则以 `TASK_10_ledger.md` 为准。

## 1. 产品气质

小步计划是家庭执行工具，不是营销页，也不是儿童插画应用。界面安静、清楚、耐看，方便每天反复用。

- **像成熟 App 一样简洁**：能简单显示的就简单显示；页面上不放解释规则的说明文字、不放“后台说明”式的按钮，规则靠分区、标签和图标本身表达（操作提示最多放在 `title` 里）。
- 信息层级优先于装饰；少量明确色彩，不让整页被单一颜色占满。
- 区块用留白和分隔线组织，卡片只包真正独立的信息单元；禁止卡片套卡片。
- 不用渐变、装饰光斑、大面积毛玻璃或夸张阴影（庆祝动画例外，见 §7.6）。
- 页面里不出现英文小标题。

## 2. 色板

颜色同时注册在 `tailwind.config.js` 和 `src/styles/index.css`。

| Token | 色值 | 用途 |
|---|---:|---|
| `ink` | `#202925` | 正文、电脑侧栏、分段切换选中底 |
| `paper` | `#F4F2ED` | 页面底色 |
| `primary` | `#2B7656` | 链接、选中、完成、主要确认（白字 5.5:1，作文字放在 `paper` 上 4.9:1） |
| `mint` | `#DCEAE3` | 轻选中背景、柔和反馈 |
| `alert` | `#E36B4E` | 新建等关键行动、逾期、“记一笔支出”、周末日期 |
| `muted` | `#6E7772` | 辅助信息 |
| `sun` | `#EFC66A` | 未同步、提示条、存款点 |

- `alert` 只用于需要马上注意或执行的元素，不做大面积背景；进度条用 `primary`。
- 学科只用 8px 色点 + 文字区分：语文 `#D96A52`、数学 `#5868C8`、英语 `#9364C7`、其他 `#8A948F`（`components/GroupHeading.tsx` 的 `SUBJECT_DOT`）。不用整条学科底、学科左边线或每条任务的学科色块。
- 奖励提示用琥珀色：`sun/35` 底、`amber-800` 字。
- 危险删除用 Tailwind `rose`；课程、状态等业务色沿用各自语义。

## 3. 应用框架

### 3.1 品牌图标

- 唯一品牌图标是 3×3 圆点：右上角橙点（`alert`）表示今日，其余深绿 `primary` / 浅绿 `mint`，底色 `#F4F2ED`。主色变了图标要跟着重出。
- 源文件在 `public/`：`icon.svg`、`icon-1024.png`、`favicon.svg` / `.ico` / `.png`、`apple-touch-icon.png`（180）/ `-167` / `-152`、`icon-192.png` / `icon-512.png`。
- 页面内 logo 一律 `<img src="/favicon.svg">`。换图标后把 `public/sw.js` 的 `VERSION` 加一。

### 3.2 设备与导航

按设备分，不按宽度分：

- **电脑**（tailwind `desk` 断点：`(min-width:1024px) and (hover:hover) and (pointer:fine)`）：固定左侧栏 `14rem`、`ink` 底；品牌（40px 图标）、新建任务、一级导航、备忘录；底部“设置”入口，右侧云同步状态点。主内容用 `.app-content` 让出侧栏。
- **手机和 iPad**（不管横竖屏）：顶栏 `h-12`（28px 图标 + 15px“小步计划”、同步点、36px 设置和新建按钮）+ 固定底部标签栏（纯白半透明，12px 字，每格至少 48px 高，选中项顶部 `alert` 短线，宽屏居中 `max-w-2xl`）。不显示备忘录。页面用 `pb-content` 避开底栏和安全区。
- 页面内容分栏仍按宽度断点（`lg` 等）走，iPad 横屏照样左右两栏。
- **一级菜单 5 项**：今日 / 计划（月历、全部任务）/ 课表 / 统计（练习、上课）/ 记账。设置在电脑侧栏底部、手机和 iPad 顶栏齿轮。
- 计划、统计页顶部是分段切换 `components/SegmentedTabs`：白底细边框圆角胶囊，选中 `ink` 底白字，每格 44px 高、带 16px 图标；手机撑满一行等分，`sm` 起按内容宽靠左。每页记住上次的标签（localStorage `nav_plan_tab` / `nav_stats_tab`，只记本机）。今日页的月历按钮直接打开“计划 › 月历”。
- 除今日页外各页按需加载；部署后旧页面文件加载失败时自动整页刷新一次。

### 3.3 手机和 iPad 的尺寸

- 整体紧凑：非电脑布局下 `html` 根字号 15px（rem 字号和间距一起缩约 6%），任务小项 14px。电脑上用大一号。
- **一屏放下**（`index.css` 的 `--fit-h` = 视口高 − 顶栏 − 底栏 − 安全区，`.fit-screen` / `.fit-tablet` / `.fit-fill`）：整页正好铺满顶栏和底栏之间，放不下的内容在各自卡片里滚动。
  - 手机和 iPad：**统计**、**课表**；
  - 只在 iPad（宽 ≥640，`TABLET_FIT_QUERY`）：**月历**、**记账**；
  - **今日页**、**全部任务**照常往下滑；电脑不受影响。

### 3.4 内容宽度

| 页面 | 宽度 |

| 今日 | `max-w-3xl`，`lg` 起铺满，`xl` `max-w-7xl` |

| 全部任务 | `max-w-4xl`，`xl` `max-w-6xl` |

### 3.5 侧栏备忘录（只在电脑）

- 在一级导航下方，侧栏深色体系里的低对比输入框；最少三行，随内容自动增高，超过视口时整个侧栏滚动。
- 勾选图标完成：归档到“设置 → 历史备忘”（默认折叠，细分隔线列表，完成时间 + 全文，留最近 50 条）并清空。恢复追加到当前备忘；永久删除二次确认；按钮点击区至少 44px。

## 4. 页面标题与字号

### 4.1 页面表头

今日、计划、课表、记账、设置共用 `.page-header` / `.page-title`（计划页的表头在分段切换下面；统计页的标签下直接是内容卡片，没有页标题）：

- 电脑：表头高 `5rem`，底部细边线；标题 30px / 36px 粗体。
- 手机和 iPad：表头不固定高（至少 44px），下边距 10px；标题 22px / 28px。
- 操作按钮和辅助日期放在同一表头里，标题左对齐。

### 4.2 字号层级

页面内容不出现 10px、11px（课表、作息时间的次要小字除外）：

| 层级 | 规格 | 用途 |
|---|---|---|
| 页面标题 | 见 4.1 | `.page-title` |
| 区块 / 任务标题 | 16px，区块粗体、任务半粗 | 任务名、区块名 |
| 正文 | 15px（手机和 iPad 小项 14px） | 小项、正文 |
| 控件 | 14px（`text-sm`） | 按钮、输入框、菜单 |
| 辅助 | 13px | 分组标题、时间、计数、备注、徽章 |

时间用常规字体加 `tabular-nums`，不用等宽小字。

## 5. 表面、按钮与控件

- `.surface` 是主要信息容器：白色、1px 低对比边框、轻阴影、8px 圆角。输入框和命令按钮 `rounded-lg`；小标签 `rounded` / `rounded-md`；状态点可 `rounded-full`。
- 关键命令 `bg-alert text-white`（“新建任务”“保存任务”）；常规确认 `bg-primary text-white`；次级命令白底、`border-ink/10`、`text-muted`。
- 图标命令用 Lucide 图标并带 `aria-label` / `title`。
- 筛选用分段控件或下划线标签，不用一排彩色药丸；所有分段按钮和选项的选中态统一 `primary` 实心（顶部页面切换除外，见 3.2）。
- 二元设置用 checkbox / toggle；日期、数字、选项用对应原生控件。

## 6. 任务行

- 任务行是紧凑的工作列表，不是浮动卡片。行之间 `border-ink/[0.07]`，hover 只出现极浅灰底。
- 主勾选框视觉 28px、热区 44px；小项勾选框 20px，小项整行可点，行高鼠标 32px、触屏 44px。“…”按钮触屏热区 44px，菜单点外面或 Esc 关闭。
- 带小项的**非重复**任务左侧是 28px 只读进度环，小项全勾完自动完成；重复任务的小项跨天共用、当天完成记在单日状态上，保留整体勾选框。
- 标题 16px 半粗，标签与备注 13px；小项用左边线缩进，15px。
- 勾选反馈在行内：勾选框动画 + 标题划线变灰，刚完成的在原位停约 0.7 秒再收进“已完成”，进度立刻更新。勾选成功不弹提示，只有补记到过去日（“已记为 M/D 完成”）和同步失败才提示。
- 查看日之前就做完的小项收成一行“✓ 之前已完成 N 项”放在最后，点开可看、可取消。
- 逾期由分区标题表达，行内不重复“已逾期”；顺延或逾期的只标“原定 M月d日”，时段任务标“截止 M月d日”。任务行只保留“进行中 / 已取消”胶囊。
- 未同步徽章持续可见、可点击重试。
- 当天记录：以前写过的在标题下显示一行“小本子 + 内容”，点它可改，清空即删；不能新写。
- **拖拽排序**（`hooks/useSortableList`）：只从手柄拖，手柄**只在电脑上显示**（`[@media(pointer:fine)]:flex`）。任务手柄在“…”左边，学科整组手柄在分组标题最右；拖动中那一行浮起跟手，其他行让位，靠近边缘自动滚动，Esc 取消，键盘 ↑/↓ 移一格；松手立刻显示新顺序，写库在后台。批量管理、搜索、筛选时不能排序。

## 7. 今日页

### 7.1 表头

- 日期一行“11月25日 星期三”（不写年份；手机和 iPad 日期 19px 粗体、星期 15px 灰），节日节气紧跟日期；右边 ‹ 今天 › 小按钮（手机和 iPad 32px 高，“今天”56px 宽）。
- **积分胶囊**（`components/PointsPanel.tsx`）：左半白底“本周 N 分”、右半主色底白字“待兑现 N 分”（多兑了时写“多兑 N 分”），点一下打开积分明细（最上面“待兑现 N 分 / 多兑了 N 分，下次抵扣”，最下面“兑现记录”）。`lg` 起在日期和按钮中间（44px 高、数字 17px），窄屏在日期下面一行居中（36px 高、数字 15px）。钱只在记账页看。
- 周日 20 点后到周一，表头下多一条 `sun/15` 圆角条“🎉 上周 N 分，M 项达标。”（不写钱），点一下收起（只记本机）。
- 看的不是今天时，表头下一整行 `sun` 浅底提示“正在看 M月d日（昨天 / 明天 / N 天前…），不是今天”+“回到今天”。跨零点或后台超过 30 分钟回到前台，自动回到今天。左右滑动换天。
- 今日页左右内边距：手机 12px、iPad 20px。

### 7.2 明日必带

看今天时，表头下面一条 `#EAF4F2` 底细边框圆角条（`utils/carryItems.ts`、`data/carryRepository.ts`）：

- 书包图标 + 粗体“**明日必带**”（点它打开课表），后面每样东西一个白底小标签，没有时写“没有要带的”（常驻的和只这一天的看起来一样，今日页上不标图钉）；最右一个笔图标打开编辑。
- 顺序：课表里明天勾了“要带”的课（“英语（课本）”写“英语课本”、“音乐（葫芦丝）”写“葫芦丝”、没括号写课名；周末或放假没有）→ 常驻的 → 只这一天补充的；同名只留一个。
- 编辑弹窗不写说明文字：每样一行，自己加的东西后面一个图钉（琥珀实心 = 常驻，灰色空心 = 只这一天），最右 × 删掉（课表来的删掉只影响那一天，常驻的删掉就是不再常驻）；最下面输入框（占位“加一样”）+ 图钉，回车加入，直接点保存也会带上输入框里的。
- 存 app_settings `carry_reminders_v2`：`{ pinned: [...], days: { 日期: { added, removed } } }`，按日期的只留 30 天；旧的 `carry_overrides_v1` 读进来当 days。

### 7.3 两栏布局

- 左栏 **“学校家庭作业”**：逾期 → 今天的作业（按学科分组）→ “其他 · 提醒” → “本周课外作业” → 已完成。右栏 **“每周练习”**。没有每周练习时左栏占满。
- `lg` 起左右两栏等宽、等高，短的一栏由主卡片拉长补齐；窄屏依次排：逾期、作业、每周练习、已完成（两栏外壳窄屏 `display: contents`，用 `order` 排）。
- 查看未来的日子不显示逾期区。
- 分组规则：上课由 `isCourseTask` 判定；其余归作业，按 `taskSubjectGroup` 分语文、数学、英语、其他（`GroupHeading`：13px 半粗、无底色，组间细分隔线）；带时间的置顶；空分组不渲染，每个任务只进一个组。“其他 · 提醒”（`isReminderTask`）排在学科作业之后、本周课外作业之前。
- “已完成”平铺，不按学科分组。

**标题栏**（`CardHeader`）：第一行粗体标题（手机 15px、电脑 17px）+ 可选奖励胶囊 + 右侧圆角小标签——作业写“还剩 N 项”（`stone-100` 底）/“全部完成”（`primary/10` 底），每周练习写“已做 N/M 次”/“本周都做够了”；第二行通栏 6px 进度条（`stone-200` 轨道、`primary` 填充）。有小项按小项计，没有按任务计。“其他”提醒、休闲、旅游可以打勾但不算进计数（`isUncountedTask`），考试比赛照常计入。

**奖励胶囊**（`RewardHint`，积分开启时显示，和标题同一行，手机 12px、电脑 13px，14px `Gift` 图标）：“本周课外作业”后面“🎁 提前完成加 3 分”（数字取 `EARLY_POINTS`），“每周练习”后面“🎁 每项全完成另加 2 分”（数字取 `REACH_BONUS`）。

### 7.4 本周课外作业

- 放**课外班等非学校**的时段（`dateRange`）作业，截止日前哪天做都行；**学校作业**（如周末家庭作业，周六到周日）即使是时段，也和单日家庭作业一样放在“学校家庭作业”今天的作业里，每天都算在“还剩 N 项”里，做完不加分；截止日当天回到今天的作业里标“今天截止”，过了没做完进逾期。判定只在 `isWeekPlanTask`。其他安排（旅游、休闲、考试比赛）不进这里。
- 不分学科，可拖动排序（`sortOrder`），没拖过的按截止日。截止标签在标题行右侧（`h-5 rounded px-1.5`，13px 半粗）：“今天截止”`alert/10` 底红字、“明天截止”`amber-100` 底琥珀字、更晚的 `primary/10` 底主色字；完成后变灰。
- 小项直接展开逐项勾。做完的（包括本周早些天做完的）并入“已完成”，“还剩 N 项”也算它们。

### 7.5 每周练习（`timeType: "weeklyTimes"`）

- 每行：左侧 28px 进度环（本周已做 / 目标）；名字后面琥珀色“N 分”（每次几分）；右边“5/10 本”；超出目标又还没计分时另写“本周多读了 N 本”（本周练习全部达标后 RAZ、FCE 语用多做的也计分，就不再写）。
- 标题下 7 个 28px 圆点（触屏 32px），一～日，点哪天记哪天（往回翻就是补记；今天以后、任务结束以后变浅不可点；按整周算，不受开始日限制）；查看的那天加浅色外圈。做了 1 份显示 ✓，好几份显示数字。
- **轻点**：没记 → ✓，记了 1 份 → 取消，好几份 → 打开填数。**右键 / 长按 500ms**：圆点下方白底小卡片（数字框 + 单位 + ✓），回车 / ✓ / 点别处保存，Esc 取消，填 0 清掉，一天最多 50。没有加减按钮。
- 做够目标的先在原位停约 0.7 秒，再收进区底“已做够 N”，超过目标照样能记。标题栏进度按总次数（各项目标之和 vs 已做之和，每项最多算到目标）。
- 区底一行 13px“家长奖励 +N”，本周有提前完成的作业时右边主色“提前完成 +N”。

### 7.6 完成反馈与庆祝

- 当天学校作业全做完：左栏一条 `mint/70` 底、8px 圆角横条，20px `Sparkles` + 17px 粗体主色“**今天的作业做完了，快去赚积分吧！**”（一行不换行，手机 16px）。今天的事全部做完（逾期也清空）时只有这一处反馈；没有积分或没有学校作业时只写一行主色“今天的事都做完了！”；其他日子写“这一天的事都做完了”。
- **庆祝**（不加声音；`prefers-reduced-motion` 下不散花；补记以前的日子不庆祝；颜色形状共用 `utils/confetti.ts`）：
  - **练习打勾**（每次都有）：屏幕正中白色小胶囊“+2 分”（数字 48px 圆体 `.points-float`、“分”20px 主色 60%；不得分时 32px `Check` +“做完了”），弹出回弹 + 粉色波纹 + 26 片彩色散花（圆点 / 花瓣 / 彩条，12–24px，粉、橙、天蓝、淡紫、黄、橙红、主色绿、浅绿、玫红），约 1.6 秒上浮淡出，不挡点击。

## 14. 可访问性

- 纯图标按钮都有可读名称；可点击目标尽量不小于 36px，移动端主要动作不小于 40px。
