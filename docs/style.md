# 小步计划 · UI 样式规范

> 全站 UI 的唯一视觉参照。新增页面和组件应复用本文 token 与布局，不在业务组件中另起一套风格。

## 1. 产品气质

小步计划是一套家庭执行工具，不是营销页，也不是儿童插画应用。界面应安静、清楚、耐看，方便每天反复使用。

- 信息层级优先于装饰。
- 使用少量明确色彩，不让整页被单一绿色或紫色占满。
- 页面区块尽量用留白和分隔线组织；卡片只包裹真正独立的信息单元。
- 桌面端使用固定侧栏，移动端使用顶部品牌栏与底部导航。
- 不使用渐变、装饰光斑、大面积毛玻璃或夸张阴影。

## 2. 色板

颜色同时注册在 `tailwind.config.js` 和 `src/styles/index.css`。

| Token | 色值 | 用途 |
|---|---:|---|
| `ink` | `#202925` | 正文、桌面侧栏、月历表头 |
| `paper` | `#F4F2ED` | 页面底色 |
| `primary` | `#2B7656` | 链接、选中态、完成态（2026-11-13 由 `#245747` 提亮；白字 5.5:1、作文字放在 `paper` 上 4.9:1，均满足 4.5:1） |
| `mint` | `#DCEAE3` | 轻选中背景、柔和反馈 |
| `alert` | `#E36B4E` | 新建等关键行动、逾期提醒、当前位置标识 |
| `muted` | `#6E7772` | 辅助信息 |
| `sun` | `#EFC66A` | 未同步等警示 |

颜色语义：

- 深松墨 `ink` 负责结构与稳定感，提亮后的 `primary` 负责选中、完成和主要确认。品牌图标里的深绿与 `primary` 同为 `#2B7656`（2026-11-14 统一）。
- 珊瑚橙 `alert` 只用于需要立刻注意或执行的元素，不用于大面积背景。
- 学科只用 8px 色点加文字区分（语文 `#D96A52`、数学 `#5868C8`、英语 `#9364C7`、其他 `#8A948F`，定义在 `components/GroupHeading.tsx` 的 `SUBJECT_DOT`）。今日页与任务管理页的分组标题统一用 `GroupHeading`：13px 半粗、无底色、无左边线，分组之间只用细分隔线。不再使用整条浅色学科底、4px 学科左边线，也不再给每条任务加学科色块。
- 任务管理页的大类标题（学校作业 / 课外 / 兴趣班 / 事项）只用文字，不加彩点，避免与学科色点撞色。
- 进度条用 `primary`，`alert` 只留给新建按钮和逾期。
- 危险删除使用 Tailwind `rose`；课程、状态等业务色沿用各自已有语义。

## 3. 应用框架

### 品牌图标

- 唯一品牌图标是“打卡点阵”：3×3 圆点，右上角橙点（`alert`）表示今日，其余为深绿 `primary #2B7656` / 浅绿 `mint`（已完成/待做），底色 `#F4F2ED`。主色再变时图标要跟着重出。
- 源文件在 `public/`：`icon.svg`（原图）、`icon-1024.png`（原图位图）、`favicon.svg` / `favicon.ico` / `favicon.png`（浏览器标签）、`apple-touch-icon.png`（180）/ `-167` / `-152`（iOS 主屏）、`icon-192.png` / `icon-512.png`（PWA manifest）。
- 页面内的 logo 一律用 `<img src="/favicon.svg">`，不再使用 Lucide 的日历图标做品牌；旧图标已删除，不要恢复。
- 换图标后必须把 `public/sw.js` 的 `VERSION` 加一，否则 Service Worker 会先给缓存的旧图标。

### 桌面端（`lg` 及以上）

- 固定左侧栏宽 `14rem`，背景 `ink`。
- 品牌、新建任务、一级导航都在侧栏中；侧栏底部是“设置”入口，右侧附云同步状态点。品牌 logo 为 40px 打卡点阵图标（`/favicon.svg`，`h-10 w-10 rounded-lg`）。
- 主内容通过 `.app-content` 留出侧栏宽度。
- 内容最大宽度由页面决定：今日页手机与 iPad 竖屏 `max-w-3xl`，出现侧栏后（`lg`，iPad 横屏）铺满可用宽度，Mac 宽屏（`xl`）`max-w-7xl`（2026-11-17 由 6xl 放宽）；任务管理 `max-w-4xl`，Mac 宽屏 `max-w-6xl`；月计划 `max-w-7xl`；打卡页与今日页同一规则（`lg` 铺满、`xl` `max-w-6xl`），保证 31 天的打卡矩阵在 Mac 上不用横向滚动；设置 `max-w-3xl`。（2026-11-13 第 3 批曾把今日页统一收到 `max-w-3xl`，iPad 横屏和 Mac 上内容只剩 688px，用户反馈太窄后改为按断点放宽。）

### 移动端

- 导航按设备分（2026-11-21）：**电脑**（宽 ≥1024 且有鼠标 / 触控板，tailwind `desk` 断点 `(min-width:1024px) and (hover:hover) and (pointer:fine)`）用左侧深色边栏，边栏里有备忘录；**手机和 iPad**（不管横竖屏）都用顶栏 + 固定在屏幕底部的标签栏，标签栏五项（今日 / 计划 / 课表 / 统计 / 记账，12px 字、每格至少 48px 高）在宽屏上居中（`max-w-2xl`），不显示备忘录。页面内容的分栏仍按宽度断点（`lg` 等）走，iPad 横屏照样左右两栏。
- 顶部栏高 `h-14`，显示品牌（32px 打卡点阵图标 `/favicon.svg` + “小步计划”）、同步点、设置图标和新建图标。
- 底部导航使用纯白半透明背景，选中项用顶部 `alert` 短线标识。
- **页面整理（2026-11-25）**：一级菜单 5 项——**今日**、**计划**（月历 / 全部任务，原“月视图”“任务管理”）、**课表**（常看，单独一项）、**统计**（打卡 / 上课，原“周计划及打卡”）、**记账**；设置位置不变（Mac 侧栏底部、手机 / iPad 顶栏齿轮）。计划、统计页顶部是分段切换 `components/SegmentedTabs`：白底细边框圆角胶囊，选中 `ink` 底白字，其余灰字 hover 浅灰，每格 44px 高、带 16px 图标；手机撑满一行三等分，`sm` 起按内容宽靠左。每页记住上次看的标签（localStorage `nav_plan_tab` / `nav_stats_tab`，只记本机）；今日页的月历按钮直接打开“计划 › 月历”。计划的两个标签各自保留原来的表头（月份切换、“全部任务”+ 批量管理）；统计的三个标签直接是内容卡片，不再有页标题。
- 页面必须使用 `pb-content` 避开底栏与 iPhone 安全区。
- 备忘录只在电脑左侧边栏里；手机和 iPad 不显示（2026-11-21 用户要求，原先窄屏放在今日页表头下、顶栏有“备忘”按钮，已去掉）。

### 侧栏备忘录

- 桌面端放在一级导航（今日 / 计划 / 课表 / 统计 / 记账）下方，使用侧栏深色体系中的低对比输入框。
- 输入框最少三行，随输入、换行和可用宽度自动增高或缩小，完整显示内容。内容超过视口时由整个侧栏滚动，导航和同步状态均可到达。
- 完成按钮使用勾选图标；完成后归档到历史备忘并清空当前内容。窄屏内容为空且未编辑时不渲染备忘录区。
- 历史备忘位于“设置 → 历史备忘”，默认折叠，使用细分隔线列表展示完成时间和完整文字，保留最近 50 条。恢复、永久删除按钮点击区至少 44px；永久删除需二次确认。恢复追加到当前备忘，避免覆盖已有文字。

## 4. 页面标题

今日、计划（月历 / 全部任务）、课表、设置共用 `.page-header` 和 `.page-title`（计划页的表头在分段切换下面）：

- 页面表头固定高 `5rem`（80px），底部边线、内边距和后续内容间距一致；手机、iPad、Mac 同一规则。
- 主标题字号：手机 `20px / 24px` 行高，iPad `24px / 32px`，Mac `30px / 36px`，统一加粗。
- 操作按钮与辅助日期放在同一表头内；窄屏时月视图只显示翻月箭头，今日页极窄屏可将日期导航放到第二行，保持表头总高度。
- 标题默认左对齐。课表的日期和学期名是辅助信息，不改变主标题规格。

## 4.5 字号层级

页面内容只用以下几级，不再出现 10px、11px：

| 层级 | 规格 | 用途 |
|---|---|---|
| 页面标题 | 见 §4 | `.page-title` |
| 区块 / 任务标题 | 16px（`text-base`），区块加粗、任务半粗 | 今日清单、已完成、逾期未完成、任务名 |
| 正文 | 15px | 小项、需要阅读的正文 |
| 控件 | 14px（`text-sm`） | 按钮、输入框、菜单 |
| 辅助 | 13px | 分组标题、时间、计数、备注、顺延说明、徽章 |

时间用常规字体加 `tabular-nums`，浅底小圆角，不再用等宽小字。

## 5. 表面与圆角

`.surface` 是主要信息容器：白色、`1px` 低对比边框、轻阴影、`8px` 圆角。

| 元素 | 规则 |
|---|---|
| 主信息容器 | `.surface` |
| 输入框、命令按钮 | `rounded-lg`（8px）|
| 小标签 | `rounded` / `rounded-md` |
| 状态点、头像式计数 | 可使用 `rounded-full` |
| 弹窗 | 移动端顶部可贴边，桌面端 `rounded-lg` |

禁止卡片套卡片。分组内部优先使用分隔线、浅底标题条或左边线。

## 6. 按钮与控件

- 关键命令：`bg-alert text-white`，例如“新建任务”“保存任务”。
- 常规确认：`bg-primary text-white`。
- 次级命令：白底、`border-ink/10`、`text-muted`。
- 图标命令优先使用 Lucide 图标并提供 `aria-label` / `title`。
- 筛选使用下划线标签页或分段控件，不使用一排彩色药丸。
- 二元设置使用 checkbox/toggle；日期、数字和选项继续使用对应原生控件。

## 7. 任务列表

- 任务行为紧凑的工作列表，不是独立浮动卡片。
- 行之间使用 `border-ink/[0.07]`；hover 仅出现极浅灰底。
- 主勾选框视觉 28px、点击热区 44px；小项勾选框视觉 20px，小项**整行可点**，行高鼠标设备 32px、触屏（`pointer: coarse`）44px。任务行“…”按钮触屏热区同为 44px。
- 带小项的**非重复**任务左侧不放整体勾选框，改为 28px 只读进度环；小项全部勾完后自动完成，不提供一键全勾。重复类任务的小项跨天共用一份、当天是否完成记在单日状态上，仍保留整体勾选框。
- 逾期区由分区标题表达状态，行内不再重复“已逾期”胶囊；顺延或逾期任务只标“原定 M月d日”，几天内做完的任务标“截止 M月d日”。
- 任务行操作菜单点菜单外或按 Esc 关闭。
- 勾选的反馈在行内完成：勾选框动画 + 标题划线变灰，刚完成的任务在原位停留约 0.7 秒再收进“已完成”，进度条和“还剩 N 项”立刻更新。勾选成功**不弹提示**；只有补记到过去日（“已记为 M/D 完成”）和同步失败才提示。
- 标题 `text-base font-semibold`（16px），标签与备注 13px，不能抢过标题。
- checklist 用左边线缩进表示从属关系，小项文字 15px。
- 在查看日之前就做完的小项收成一行“✓ 之前已完成 N 项”放在小项最后，点开可看、可取消勾选；当天刚勾的仍原地划掉，让孩子看到反馈。重复任务的小项按天显示，不会出现这一行。
- 今日页“已完成”区平铺，不再按学科重复分组；任务行不再挂“已完成”胶囊（划线和所在区已说明），只保留“进行中 / 已取消”。
- 完成任务使用灰字和删除线；未同步徽章持续可见并可点击重试。
- **当天记录**（今日页）：2026-11-21 起标题后不再有小本子图标（用户要求去掉），不能新写；以前写过的记录仍在标题下方显示一行“小本子 + 记录内容”，点它可修改，清空即删除。编辑表单“哪天做”下方只读列出“完成记录”。

今日页分两栏（2026-11-17）：左栏是作业——**“家庭作业”**（2026-11-25 用户由“今日任务”改名，看别的日子也叫“家庭作业”），里面先是今天的作业，再是“本周作业”；右栏是 **“每周练习”**（每周几次）。页面上不放解释规则的说明文字（“截止前哪天做都行……”之类），规则靠分区和标签本身表达。
- “本周作业”组（页面上的组名是“**本周课外作业**”，积分开启时后面跟一个琥珀色小胶囊“🎁 提前完成有奖励！”（右栏“每周练习”标题后同样一个“🎁 全部完成有奖励！”，组件 `RewardHint`）：`sun/35` 底、`amber-800` 13px 粗体、14px `Gift` 图标，和上面绿色的“快去赚积分”分开，2026-11-24）放时段（`dateRange`）的作业，截止日之前哪天做都行；**截止日当天**回到“今日任务”，标“今天截止”；过了截止日没做完进逾期区。“其他安排”（旅游、休闲、考试比赛）是一段时间的安排，不进本周作业。判定只在 `isWeekPlanTask`，只决定显示位置。
- 本周作业不分学科，可拖动手柄排序（写 `sortOrder`），没拖过的按截止日；截止日是标题行右侧的实底小标签（`h-5 rounded px-1.5`，13px 半粗）：“今天截止”`alert/10` 底红字、“明天截止”`amber-100` 底琥珀字、更晚的（“周六截止”“11月24日截止”）`primary/10` 底主色字；已完成的变灰。做完的（包括这周早些天做完的）并入左栏“已完成”；左栏“还剩 N 项”把本周作业也算进去。
- **每周练习**（`timeType: "weeklyTimes"`）的行：左侧 28px 进度环（本周已做 / 目标），标题右侧“5/10 本”；标题下一排 7 个 28px 圆点（触屏 32px），一～日，点哪天记哪天，往回翻也一样，以前的日子就是补记（今天以后、任务结束以后的变浅且点不了；不受开始日限制，按整周算）；查看的那天加浅色外圈。**左键 / 轻点**：没记 → 打 ✓，记了 1 份 → 取消，记了好几份 → 打开填数。**右键 / 长按（500ms）**：圆点正下方白底小卡片（数字框 + 单位 + 主色 ✓），回车 / ✓ / 点别处保存，Esc 取消，填 0 清掉，一天最多 50。做了 1 份显示 ✓（不用“一”字——实心圆上像减号），好几份显示数字。没有加减按钮、不写说明文字（操作提示只在 title 里）。做够目标的收进区底“已做够 N”（先在原位停留约 0.7 秒），超过目标照样可以记。区标题栏进度按总次数算（各项目标次数之和 vs 已做次数之和，每项最多算到目标；2026-11-19），右侧“已做 20/30 次”，全做够显示“本周都做够了 30/30”。每行有拖动手柄排序。
- 新建任务“哪天做”四个选项：单日 / 时段 / 每周几次 / 重复（手机两列、`sm` 起四列）。选“每周几次”时显示 −/+ 次数、单位（次 / 本 / 篇 / 页 / 题 / 分钟）、从哪天开始、结束日（可不填），不显示小项和“未完成处理”，不放用法说明。编辑已有的重复任务切到“每周几次”（或反过来）时，开始日期默认今天，下方一行 13px 灰字：“原任务今天结束，历史记录和打卡保留。”
- 布局：`lg` 起（iPad 横屏、Mac）左右两栏**等宽、等高**：左栏依次是逾期 / 家庭作业（含本周课外作业）/ 已完成，右栏每周练习；两栏底边对齐，短的一栏由主卡片拉长补齐（2026-11-17 用户反馈：两栏一长一短不协调；同日改为左作业、右练习）。窄屏依次排下来：逾期、今日任务、每周练习、已完成（两栏外壳窄屏为 `display: contents`，用 `order` 排）。没有每周几次时不出现右栏，左栏占满。
- 本周作业（时段）的小项直接展开在任务下面，和今天的作业一样逐项勾（2026-11-19 用户要求不再收起；原先收成琥珀色“还有 N 项未完成 ⌄”）。

两块的标题栏（`CardHeader`，2026-11-25 改版）：第一行 17px 粗体标题 + 可选琥珀提示胶囊 + 右侧圆角小标签（“还剩 N 项”`stone-100` 底正文色，“全部完成”/ 练习全做够时 `primary/10` 底主色）；第二行一条通栏 6px 进度条（`stone-200` 轨道、`primary` 填充）。“还剩 N 项”和进度条两者同一口径（有小项按小项计，没有小项按任务计），各算各的。其他安排里的“其他”（提醒）、“休闲”、“旅游”照常显示、可以打勾，但不算进“还剩 N 项”和进度条（`isUncountedTask`）；考试或比赛照常计入。

## 10. 可访问性与响应式

- 所有纯图标按钮必须有可读名称。
- 可点击目标尽量不小于 36px；移动端主要动作不小于 40px。
- 文字不得依赖颜色单独表达状态。
- 长标题和长标签必须允许换行或截断，不能推动操作按钮出屏。
- `prefers-reduced-motion` 下关闭非必要动效。
- iOS PWA 继续使用 `.pt-safe`、`.bottom-nav-safe`、`.pb-content` 与 toast 安全区类。
