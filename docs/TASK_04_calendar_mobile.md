# TASK_04 · 月历手机端适配 + 手势翻页

> **推荐模型：Sonnet**（响应式布局 + 手势，中等复杂度）
> **前置依赖：无**（可独立做）
> **先读**：`PROJECT_GUIDE.md`，再读本卡。

---

## 解决了什么问题

1. **月历手机端文字截断**：7 列网格在手机宽度下每格太窄，长标签塞不下。
2. **缺手势翻页**：手机/iPad 上希望左右滑切换（今日页切昨天/明天；月历切上月/下月；周计划切上周/下周）。
3. **整站双指缩放**：手机双指缩放会露出页面周围空白。

---

## 实际实现

### A. 月历手机端：极简标签 + 点击展开

手机端（`< sm = 640px`）每个格子显示：
- 最多 **2 个极简色块标签**：取任务标题前 4 个字（中文 4 字 / 英文同），去掉末尾" ✓"，套分类背景色（如蓝色=学校作业、紫色=钢琴课）。
- 超过 2 个：显示 `+N`。
- 格子高度 `min-h-16`（64px），不会出现截断"…"。

桌面端（`≥ sm`）保留原有完整文字标签 pill（最多 5 条 + `+N`）。

**点击展开**（手机端专用）：
- 点击某天 → `selectedDay` state 切换，日历网格下方渲染 `<DayPanel>`（`sm:hidden`）。
- DayPanel 显示：日期 + 节日/节气 + 完整任务列表（`labelClass` 色块 + 圆点 + 完整标题）+ "查看完整当日页 →" 按钮。
- 再次点击同一天或按 ✕ → 收起。
- 切换月份时自动清除 `selectedDay`。

桌面端点击格子 → 直接导航到今日页（原有行为不变）。

辅助函数：
- `shortLabel(text)` — 去 ✓ 后取前 4 字
- `compactLabelClass(type)` — 无边框的轻量色块样式（`bg-*-100 text-*-700`）
- `dotBg(type)` — DayPanel 行内小圆点颜色（`bg-*-400`）
- `labelClass(type)` — 桌面端 pill 样式（带 border）

### B. 左右滑手势翻页（跟手动画）

涉及页面：今日页（日期）、月历（月份）、周计划（周）。

**实现**：`src/hooks/useSwipe.ts`，接口不变（返回 `ref`，接收 `onLeft/onRight`）。

核心机制（全部直接操作 DOM，不触发 React 重渲染，保证 60fps）：

1. `touchstart`：记录起点坐标和时间，清除 transition。
2. `touchmove`（**non-passive**，可调 `preventDefault()`）：
   - 前 8px 等待判断方向。
   - 确认垂直 → 放行滚动，不再干预。
   - 确认水平 → 调 `preventDefault()` 锁定垂直滚动，
     `el.style.transform = translateX(dampedDx)`（rubber-band 阻尼）。
3. `touchend`：
   - 位移 > 72px **或** 速度 > 0.3px/ms → `ease-in 220ms` 飞出屏幕，`setTimeout(220ms)` 后重置 transform 并调用 `onLeft/onRight`。
   - 否则 → `cubic-bezier 320ms` 弹回原位。

**跟手区域**（关键）：
- `ref` **不绑在 `<main>` 上**，而是绑在内层内容容器上：
  - 今日页：`<div className="grid gap-6 ...">` （任务清单区）
  - 月历：`<div className="grid grid-cols-7 ...">` （日历网格）
  - 周计划：`<div ref={swipeRef}>` （包裹汇总 + 每周目标 + 每日安排三段）
- `<main>` 加 `overflow-x-hidden` 防位移溢出。
- 效果：顶部日期/月份/周标题、昨天/今天/明天等导航按钮**固定不动**，只有内容区跟手位移。

### C. 禁止整站双指缩放

`index.html` viewport meta 加 `maximum-scale=1.0, user-scalable=no`，防止手机双指缩放露出周围空白。

---

## 多端注意

- 手势只在触控设备生效（`touch` 事件在纯鼠标环境不触发）。
- `touchmove` non-passive 仅在确认水平方向后才调 `preventDefault()`，垂直滚动不受影响。
- 桌面端月历点击格子行为不变（导航到今日页）；DayPanel 只在手机端渲染（`sm:hidden`）。

---

## 不要做

- 不要改月历的数据来源和颜色分类规则（只改展示密度和交互）。
- 不要让手势和页面滚动打架。

---

## 验收标准（已全部通过）

1. 手机端月历格子显示极简色块标签，不出现"…"截断。
2. 点击某天展开 DayPanel，显示完整任务列表，有"查看完整当日页"入口。
3. 桌面端月历显示完整文字标签 pill，行为不变。
4. 今日页手机左右滑切日期，方向正确，内容跟手，顶部固定。
5. 月历手机左右滑切月份，方向正确，网格跟手，标题/导航固定。
6. 周计划手机左右滑切周，方向正确，内容跟手，标题/导航固定。
7. 上下滚动不误触发翻页。
8. 手机不能双指缩放整站。
