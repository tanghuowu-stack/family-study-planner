# 小步计划｜家庭学习生活规划系统

第一阶段本地单机版。数据保存在当前浏览器的 IndexedDB 中，不包含账号、后端或云同步。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址，默认是 `http://localhost:5173`。

生产构建：

```bash
npm run build
```

## 阶段 1A 已实现

- 今日总览与按分类分组
- 可切换日期的日视图
- 任务新增、编辑、删除与完成状态
- 单日、日期范围、周目标、月目标的数据录入基础
- 阅读、课程、地点等动态表单字段
- Dexie + IndexedDB 本地存储
- JSON 覆盖导入与导出
- 手机、平板、电脑响应式布局

周视图、重复任务的单日状态、月历和打印页属于后续阶段 1B/1C。
