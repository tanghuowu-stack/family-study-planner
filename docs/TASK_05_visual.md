# TASK_05 · 视觉配色优化 + 孩子正向反馈

> **推荐模型：Haiku 或 Sonnet**（纯样式/文案/小动画为主，便宜模型够用；若涉及主题系统改造可临时升 Sonnet）
> **前置依赖：无**（但建议放在功能稳定后做，纯视觉迭代，可随时调）
> **先读**：`PROJECT_GUIDE.md`，再读本卡。

---

## 解决什么问题

1. 视觉密度太高、层级不清，卡片都一个样找不到重点。
2. 配色是 AI 默认生成的，偏成人工作风，孩子也会用，可以更友好。
3. 完成任务没有成就感反馈，孩子缺激励。

---

## 配色方向（用户已确定）

**核心原则：鲜亮但高级、文字一目了然。颜色只用在"色块、按钮、标签底色"上，正文字一律用深色（深灰/近黑带一点绿调），不要让正文五颜六色。** 用户明确不要满屏彩色文字（看久了累、信息一多就乱）。

参考的是一个健康护理网站（Bary）的"克制用色"风格：绿色主色 + 淡薄荷绿/淡紫做点缀 + 大量留白，文字清晰。高级感来自"克制"，不是"花哨"。**注意：用户明确要求主色不要太深的绿，要清新明亮一点的草绿/薄荷绿，不要深森林绿。**

### 主色板（建议色值，可微调）
- **主色 / 品牌色**：清新草绿，约 `#5BA678` 或 `#6BB089`（用于顶栏、主按钮、标题、重点强调）。**明亮清新，不要深森林绿。**
- **辅助底色 1**：淡薄荷绿，约 `#EAF5EC`（用于卡片背景、信息块底色）
- **辅助底色 2**：淡薰衣草紫，约 `#ECE6F7`（用于导航条、次要标签底色，做一点变化）
- **正文字色**：深灰带绿调，约 `#2A3B30`（所有正文、任务标题用这个，**保证清晰**。注意是文字用深色，不是主色用深色）
- **次要文字**：中灰绿，约 `#7A8A80`（备注、日期、次要信息）
- **强调 / 警示色**：暖橙或珊瑚红，约 `#E8743B`（**专门留给"逾期/即将到期"**，全站只有这一处用暖色，一出现就抓眼）
- **页面大背景**：米白/极浅灰，约 `#F8FAF7`（不要纯白，柔和一点更高级）

### 学科标签色（鲜亮但只用作小色块底，不用于正文字）
给每个学科一个清晰的标签底色 + 小图标，标签上的字仍用深色保证可读：
- 语文 📖 → 暖红/砖红底
- 数学 🔢 → 蓝底
- 英语 🔤 → 紫底
- 其他 → 中性灰绿底
- 兴趣班（钢琴🎹/游泳🏊/轮滑/美术🎨）→ 各给一个柔和鲜亮色
这些色块要"鲜亮但不刺眼"，彩度适中，互相能区分即可。**关键：这些颜色是标签的背景色，不是文字颜色。**

### 给孩子的部分可以再活泼一点
完成动画、连续打卡徽章、进度圆环这些"孩子直接接触、带激励性质"的元素，允许用更鲜亮、更童趣的颜色和小动效（借鉴儿童网站的活泼感），但**任务列表、文字信息区保持上面的克制风格**，两者分工：信息区求清晰，激励区求愉悦。

### 落地方式
建议把这套颜色定义成一组 **CSS 变量 / Tailwind 主题色 token**（如 `--color-primary`、`--color-mint`、`--color-alert` 等），全站引用变量。这样以后想微调配色，改几个变量就全站生效，不用到处找色值。这是这个任务里唯一可能需要从 Haiku 升到 Sonnet 的部分（建主题变量系统），改完之后的具体上色都可以用便宜模型。

## 要做的事（可分批，纯样式改动）

1. **拉开层级**：卡片间距加大，减少拥挤；重点信息（今日待办、逾期）视觉权重提高。
2. **已完成任务**自动变灰 + 删除线（增强"已完成感"），不要和未完成同样式。
3. **进度可视化**：把"今日待完成5项｜已完成0项"做成进度条或小圆环；重复任务"FCE听写 1/6次"做成小进度条。
4. **完成反馈**：勾选完成时加一个轻微弹跳/颜色填充过渡动画，给孩子成就感（不要太花哨）。
5. **学科图标 + 色块**：替换/补充现在的纯文字标签。

---

## 多端注意

- 桌面端可信息密度高、手机端留白多、按钮大。
- 动画在低端设备也要流畅，别用重特效。

---

## 不要做

- 不要为了好看牺牲可读性和触控目标大小。
- 不要改任何数据逻辑，纯展示层。
- 不要一次全改完再给用户看，建议分小批改、让用户边看边调（这是 Token 友好的迭代方式）。

---

## 验收标准

1. 页面层级清晰，一眼能看出今天还剩几项、哪些逾期。
2. 已完成任务明显区别于未完成。
3. 勾选完成有令人愉悦的小反馈。
4. 学科有清晰的颜色 + 图标识别。
5. 手机端触控舒适。

```
学科标签换成带图标的彩色底块（字仍深色）。逾期项用强调橙。改完我看效果。
```
